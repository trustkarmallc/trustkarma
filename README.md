# Trust Karma

A modern, responsive website for Trust Karma, featuring bold Indian street food and global fusion cuisine. Built with React, Tailwind CSS, and served as a static HTML page.

## Description

Trust Karma is a culinary venture that brings the vibrant flavors of Indian street food to life with innovative global fusion elements. This website showcases our menu, story, and contact information in an elegant, interactive design.

## Features

- **Interactive Menu**: Browse through categorized food items with descriptions and pricing
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Engaging fade-in and slide-up effects for a premium user experience
- **Modern UI**: Glassmorphism navigation and gradient text effects
- **Static Hosting Ready**: No build process required - open directly in any browser

## Technologies Used

- **React 18**: For component-based UI development
- **Tailwind CSS**: Utility-first CSS framework for styling
- **Babel**: JavaScript transpiler for JSX support
- **Google Fonts**: Outfit and Playfair Display for typography

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/trustkarma.git
   cd trustkarma
   ```

2. Open `index.html` in your web browser:
   - Double-click the file, or
   - Use a local server (e.g., `python -m http.server` or Live Server extension)

No dependencies or build tools required - everything is included in the single HTML file.

## Usage

Simply open `index.html` in any modern web browser. The site is fully self-contained with all assets and scripts loaded from CDNs.
